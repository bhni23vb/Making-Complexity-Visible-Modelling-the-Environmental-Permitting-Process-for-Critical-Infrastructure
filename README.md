# Swedish Environmental Permitting Process Model

This repository provides supplementary material for a practice-track contribution to the **Digital Building Permit Conference 2026 (DBP26)** in Munich.

## Scope

The contribution reports on the reconstruction and modelling of the existing Swedish environmental permitting process within **SMARTE — A Streamlined Environmental Permitting Process for Construction Projects Related to Critical Infrastructure**.

The supplementary model is a simplified example of how the permitting process was represented using Business Process Model and Notation (BPMN 2.0). It concerns the permitting process for Type B environmentally hazardous activities.

The model is provided to illustrate the process-modelling approach. It does not represent the SMARTE project as a whole, every possible environmental permitting pathway, or legal guidance.
